# RSSchool React App

A Next.js application built with React and TailwindCSS that integrates with the TCGDex API for trading card game data.

## Tech Stack

- [Next.js 15](https://nextjs.org/)
- [React](https://react.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [TCGDex API](https://tcgdex.dev/) - Pokemon Trading card game database

## Getting Started

### Installation

1. Clone the repository

```bash
git clone https://github.com/wingedseraph/rs-react-app.git
cd rs-react-app
```

2. Install dependencies

```bash
pnpm install
```

3. Run the development server

```bash
pnpm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
